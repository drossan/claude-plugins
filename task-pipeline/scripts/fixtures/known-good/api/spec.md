# Spec — carrito

## User stories
- **US-1 (P1)** — Como cliente, quiero añadir productos, para comprarlos.

## Requisitos funcionales (EARS)
- **FR-001** — El sistema DEBERÁ persistir el carrito.
- **FR-002** — Cuando el cliente añade un producto, el sistema DEBERÁ recalcular el total.

## Criterios de éxito
- **SC-001** — El total refleja los productos en < 200ms.
