# Índice de ADR

> **Plantilla SDD** (índice MADR). Materialízala en `.claude/specs/adr/adr-index.md`. **Gated por
> `features.sdd`** (opt-in, default off).
>
> **Numeración**: `NNNN-titulo.md` desde **`0001`**, ancho fijo de **4 dígitos** (preserva el orden
> lexicográfico). **No existe `ADR-0000`** de relleno: el índice arranca **vacío** y la primera decisión
> real entra como `0001-...`. El **estado de cada fila es el de su ADR** (fiel a la fuente: `proposed` /
> `accepted` / `rejected` / `deprecated` / `superseded`).
